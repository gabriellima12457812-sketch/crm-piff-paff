Política de Privacidade do CRM Piff-Paff

Última atualização: 10 de Setembro de 2026

1. Finalidade

Esta API e integração com o ChatGPT são utilizadas exclusivamente pela equipe comercial interna da Caribe Móveis / Piff-Paff para gerenciamento de clientes, negociações e acompanhamento de propostas no CRM oficial.

2. Coleta e Uso de Dados

Os dados processados incluem nome, telefone, estágio de negociação, valor de propostas e notas comerciais dos clientes atendidos. Todos os dados são transmitidos de forma segura e armazenados exclusivamente nos bancos de dados corporativos protegidos.

3. Compartilhamento

Nenhuma informação é compartilhada com terceiros para fins de publicidade ou comercialização.

4. Segurança

A comunicação ocorre exclusivamente através de conexões criptografadas com TLS/HTTPS.
